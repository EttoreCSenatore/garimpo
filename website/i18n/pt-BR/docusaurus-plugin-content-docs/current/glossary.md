# Glossário

| Termo | Significado |
| --- | --- |
| **Garimpo / garimpar** | Procurar com paciência uma boa descoberta ou pechincha |
| **Atualização completa** | Percorrer todas as categorias e páginas de produto (a cada 6 h por padrão) |
| **Atualização incremental** | Reler os produtos mais vistos (200 a cada 15 min por padrão) |
| **Canário** | Checagem semanal ao vivo de que as páginas da loja ainda são lidas |
| **Interpretador de intenção** | A etapa por regras que transforma uma mensagem em filtros |
| **Acompanhamento** | Comando do chat que age sobre os resultados anteriores: comparar, mais barato, histórico de preço |
| **Histórico de preços** | Linhas de `product_history`, gravadas só quando um campo monitorado muda |
| **Preço à vista / boleto** | O preço no pagamento à vista, uma porcentagem abaixo do preço no cartão |
| **Parcelas** | Parcelamento no cartão, com ou sem juros |
| **Desaparecido** | Produto cuja página não existe mais |
| **Proxy de imagens** | O endpoint da API que busca imagens da loja por uma lista exata de hosts |
| **Trava** | Os `requirements*.txt` com hashes gerados por `deploy/lock.sh` |

# Glossary

| Term | Meaning |
| --- | --- |
| **Garimpo / garimpar** | Prospecting; hunting for a good find or bargain |
| **Full refresh** | A crawl of every category and product page (every 6 h by default) |
| **Incremental refresh** | A re-fetch of the most viewed products (200 every 15 min by default) |
| **Canary** | A weekly live check that the store's pages still parse |
| **Intent parser** | The rule-based step that turns a message into filters |
| **Follow-up** | A chat command that acts on the previous results: compare, cheapest, price history |
| **Price history** | Rows of `product_history`, written only when a tracked field changes |
| **À vista / boleto price** | The cash-payment price, a percentage below the card price |
| **Parcelas** | Card instalments, with or without interest |
| **Disappeared** | A product whose page no longer exists |
| **Image proxy** | The API endpoint that fetches store images through an exact host allow-list |
| **Lock** | The hashed `requirements*.txt` generated by `deploy/lock.sh` |

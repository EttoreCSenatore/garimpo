# Development

## Layout

```text
app/            FastAPI app, scraper, search, event logging
frontend/       React + Vite + Tailwind chat UI
tests/          pytest suite (HTTP mocked with respx)
website/        This documentation (Docusaurus, English + Brazilian Portuguese)
.github/        CI, CodeQL, Dependabot, docs deployment
```

## Quality gates

```bash
ruff check . && ruff format --check .        # lint (with security rules) and formatting
python -m pytest tests -q --cov=app          # no network, temporary DB; coverage floor in pyproject.toml
cd frontend && npx tsc --noEmit && npm run build
```

CI runs the same checks plus `pip-audit`, `npm audit`, a lock freshness check and a Docker build; CodeQL scans Python and TypeScript.

## Dependencies and supply chain

- Direct dependencies live in `requirements.in` (runtime) and `requirements-dev.in` (tools). `requirements.txt` and `requirements-dev.txt` are **hash-locked** files generated by `deploy/lock.sh` inside the same Python the image uses (needs Docker). CI runs `deploy/lock.sh --check` and fails when a lock is stale; installs use `--require-hashes`.
- GitHub Actions are pinned to a commit SHA with the tag in a comment, and the Docker base image to a digest; Dependabot updates both.
- Dependabot waits 7 days after a release before proposing a version update (a compromised package is usually pulled within days); security updates are not delayed.
- Test coverage has a floor (`fail_under` in `pyproject.toml`, currently 85 % against about 88 % measured) that is meant to rise to 90 %.

## Testing notes

- `tests/conftest.py` sets a temporary database, disables the scheduler and clears rate limiters between tests.
- Scraper tests use saved HTML fixtures in `tests/fixtures/`; image-proxy tests use `respx`.
- Never add a test that hits the real site.

## Documentation

```bash
cd website
npm ci
npm start                          # English
npm start -- --locale pt-BR        # Brazilian Portuguese
npm run build
```

Keep the two languages in sync: English lives in `website/docs/`, Portuguese in
`website/i18n/pt-BR/docusaurus-plugin-content-docs/current/`.
The docs are deployed to GitHub Pages by `.github/workflows/docs.yml` on every push to `main` that touches `website/`.

## Refreshing the screenshots

Screenshots live in `website/static/img/screenshots/` and use demo data (`python -m app.seed`) so no third-party
product images are published.

## Scraper canary

A weekly workflow (`.github/workflows/canary.yml`, also runnable with `python -m app.canary`) makes about four polite requests to the real store and checks that categories, product links, name, price, images and sizes still parse. If the store changes its markup it fails within days, instead of a scrape silently returning nothing.
